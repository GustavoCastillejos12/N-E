INSTRUCCIONES PARA LOS LOGOS DE EQUIPOS
========================================

Para que los logos aparezcan correctamente en la página, debes nombrarlos de la siguiente manera:

FORMATO DE NOMBRES:
-------------------
[nombre-equipo]-logo.png
o
[nombre-equipo]-logo.jpg

NOMBRES EXACTOS REQUERIDOS:
---------------------------
- haas-logo.png (o .jpg)
- mercedes-logo.png
- redbull-logo.png
- williams-logo.png
- sauber-logo.png
- alpine-logo.png
- astonmartin-logo.png (sin espacio)
- mclaren-logo.png
- ferrari-logo.png
- racingbulls-logo.png

IMPORTANTE:
-----------
- Usa minúsculas para los nombres
- No uses espacios, usa guiones (-)
- El formato puede ser .png o .jpg
- Si el logo no se encuentra, se ocultará automáticamente
- Tamaño recomendado: 60x60px o más grande (se ajustará automáticamente)
