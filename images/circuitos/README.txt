INSTRUCCIONES PARA LAS IMÁGENES DE CIRCUITOS
=============================================

Para que las imágenes aparezcan correctamente en la página, debes nombrarlas de la siguiente manera:

FORMATO DE NOMBRES:
-------------------
r[NÚMERO]-[nombre-circuito].jpg
o
r[NÚMERO]-[nombre-circuito].png

EJEMPLOS:
---------
- r1-silverstone.jpg
- r2-silverstone.jpg
- r3-melbourne.jpg
- r4-shangai.jpg
- r5-monza.jpg
- r6-spa.jpg
- r7-monaco.jpg
- etc.

IMPORTANTE:
-----------
- Usa minúsculas para los nombres
- Separa las palabras con guiones (-)
- Usa formato .jpg o .png
- El número debe coincidir con el número de carrera (R1, R2, R3, etc.)

Si una imagen no se encuentra, se mostrará automáticamente una imagen placeholder.
