INSTRUCCIONES PARA LAS IMÁGENES DE CARROS
=========================================

Para que las imágenes de los carros aparezcan correctamente en el carrusel, debes nombrarlas de la siguiente manera:

FORMATO DE NOMBRES:
-------------------
[nombre-equipo]-car.jpg
o
[nombre-equipo]-car.png

NOMBRES EXACTOS REQUERIDOS:
---------------------------
- haas-car.jpg (o .png)
- mercedes-car.jpg
- redbull-car.jpg
- williams-car.jpg
- sauber-car.jpg
- alpine-car.jpg
- astonmartin-car.jpg (sin espacio)
- mclaren-car.jpg
- ferrari-car.jpg
- racingbulls-car.jpg

IMPORTANTE:
-----------
- Usa minúsculas para los nombres
- No uses espacios, usa guiones (-)
- El formato puede ser .jpg, .jpeg o .png
- Si la imagen no se encuentra, se ocultará automáticamente
- Tamaño recomendado: Imágenes anchas (landscape) para que se vean bien como fondo
- Las imágenes se ajustarán automáticamente al tamaño del carrusel
