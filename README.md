# N&E Series - Liga F1 25

Página web profesional para la liga de carreras N&E Series del juego F1 25.

## 🏎️ Características

- **Diseño Moderno**: Interfaz profesional con tema azul turquesa
- **Temporada 7**: Información actualizada de la temporada actual
- **Responsive**: Diseño adaptable a todos los dispositivos
- **Animaciones Suaves**: Efectos visuales profesionales

## 🎨 Colores de la Liga

- **Azul Turquesa Principal**: `#00CED1`
- **Azul Turquesa Oscuro**: `#008B8B`
- **Azul Turquesa Claro**: `#40E0D0`

## 📁 Estructura del Proyecto

```
Seires/
├── index.html          # Página principal
├── styles/
│   └── main.css        # Estilos principales
├── scripts/
│   └── main.js         # JavaScript principal
└── README.md           # Este archivo
```

## 🚀 Uso

Simplemente abre `index.html` en tu navegador web para ver la página.
